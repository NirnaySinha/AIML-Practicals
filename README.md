# Introduction to Artificial Intelligence and Machine Learning — Practicals

This repository contains implementations of the practical experiments prescribed for **Unit 1 and Unit 2** of the Introduction to Artificial Intelligence and Machine Learning course.

## Units Covered

- **Unit 1:** Introduction to AI and Intelligent Agents
- **Unit 2:** Problem Solving and Searching

---

## Practical Experiments

### Unit 1 — Introduction to AI and Intelligent Agents

| No. | Experiment |
|:---:|---|
| 01 | Create a Simple Knowledge Base Using Facts, Predicates, Clauses, and Goals (Student-Course Database) |
| 02 | Implement Arithmetic Operations, Factorial, and Fibonacci Series Using Recursion |
| 03 | Perform Append, Reverse, Member Search, and List Length Operations |
| 04 | Develop a Timetable Database and Answer Queries Regarding Faculty, Subjects, and Classrooms |
| 05 | Classify Students as Topper, Average, and Fail Using Rule-Based Reasoning |
| 06 | Implement Breadth-First Search (BFS) to Find the Shortest Path in a Graph |

### Unit 2 — Problem Solving and Searching

| No. | Experiment |
|:---:|---|
| 07 | Implement Greedy Best-First Search Using a Heuristic Function to Find a Path in a Graph |
| 08 | Implement the A* Search Algorithm to Find the Optimal Path Using Path Cost and Heuristic Estimate |
| 09 | Implement Hill Climbing for Optimization Problems |
| 10 | Solve an Optimization Problem Using Simulated Annealing to Escape Local Optima |
| 11 | Represent a Map-Coloring Problem as a CSP and Solve It Using Backtracking Search |
| 12 | Solve the N-Queens Problem Using Backtracking to Satisfy CSP Constraints |

---

## Repository Structure

Each experiment is organized into its own directory containing the source code and a dedicated README file documenting the aim, theory, algorithm, implementation, sample queries or output, and conclusion.

## Technologies Used

- Prolog
- Artificial Intelligence Search Algorithms
- Constraint Satisfaction Problems (CSP)
- Git and GitHub

## Purpose

This repository serves as a record of academic practical work and a reference for learning fundamental AI concepts, logical programming, search algorithms, and problem-solving techniques.
